# 💜 Violet Launcher abandoned

**A modern Minecraft launcher with a beautiful Dark Violet interface.**

Violet Launcher is a desktop application designed to make managing Minecraft installations easier. Built with Tauri, React, TypeScript, and Rust, it combines a modern user interface with native desktop performance.

---

## ✨ Features

- 🎨 **Dark Violet UI** — A sleek dark interface with violet accents.
- 🎮 **Minecraft Versions** — Browse and install available Minecraft versions.
- ☕ **Java Detection** — Detect installed Java runtimes and configure the Java executable.
- 🧩 **Mod Loader Support** — Install supported Minecraft mod loaders.
- 📦 **Mod Management** — Discover and manage mods through Modrinth and CurseForge integrations.
- 👤 **Game Profiles** — Organize different game configurations.
- ⚙️ **Launch Configuration** — Configure JVM arguments and launch settings.
- 🖥️ **Native Desktop App** — Lightweight application powered by Tauri and Rust.

## 🚀 Development Setup

### Requirements

- Node.js and npm
- Rust (stable toolchain)
- Microsoft C++ Build Tools
- Windows 10 or Windows 11

### Installation

Clone the repository:

```bash
git clone https://github.com/redmi14cusergg-a11y/violet-launcher.git
cd violet-launcher
```

Install dependencies:

```bash
npm install
```

Start the development environment:

```bash
npm run tauri dev
```

### Build

Build the frontend:

```bash
npm run build
```

Build the desktop application:

```bash
npm run tauri build
```
